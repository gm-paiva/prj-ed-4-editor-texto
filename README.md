# Editor de Texto

Editor de texto web desenvolvido em React (Vite) e TypeScript.

## Funcionalidades

- Desfazer e refazer ações (duas pilhas)
- Substituir uma ou todas as ocorrências de uma palavra
- Exportar o texto como PDF

## Como rodar

    npm install
    npm run dev

## Tecnologias

- TypeScript
- React (Vite)
- jsPDF
